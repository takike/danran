# タスク 5-2 フォローアップ：完了したやることを、ふだんは隠す

- ブランチ名: `phase5/5-2-hide-done-tasks`（最新の main から分岐）
- 作業前に読むもの: [AGENTS.md](../../AGENTS.md)（UI の規約）、[docs/21-tasks.md](../21-tasks.md)、`src/shared/domain/taskPresentation.ts`、`src/client/features/tasks/TasksPage.tsx`、`src/client/features/tasks/TaskRow.tsx`

## 背景

実機確認（2026-10-14）での指摘：「やることで、終わったものがずっと見えてしまう」。

いまは、API が返す「完了してから 14 日以内」のやることを、すべて表示している。「予定ごと」では、すべて完了した過去の予定のカード（「終了」）も残り続ける。

## 目的

ふだんは、まだ終わっていないやることだけが見える。完了したものは、必要なときだけ開いて見られる（間違えて完了にしたものを、戻せるようにするため）。

## 画面（`/tasks`。サーバーは変えない）

- **完了したやることは、どの表示（予定ごと・期限順・自分の担当）でも、一覧から外す。**
  - 「予定ごと」：予定のカードには、未完了のやることだけを並べる。**未完了のやることが1つもない予定のカードは、出さない。** カードの進捗（「1/3 完了」とバー）は、これまでどおり完了したものも数える。
  - 「期限順」「自分の担当」：いまの「完了」の見出しの下のまとまりを、下の折りたたみに置き換える。
- 一覧の最後に、折りたたみ「完了したやること（N件）」（`<details>` と `<summary>`。**既定は閉じる**。0 件なら出さない）。開くと、完了したやることを、完了した時刻の新しい順に並べる。予定にひもづくものは、予定のタイトルと日付を小さく添える。チェックを外すと未完了に戻り、元の場所に出る。「自分の担当」の表示では、自分が担当のものだけを数えて並べる。
- **この画面で完了にしたやることは、その場に残す**（取り消し線と「済」のまま）。画面を離れる、または表示を切り替えるまでは、一覧から外さない（押した瞬間に行が消えて、ほかの行が動くのを防ぐため。押し間違えをすぐに戻せるようにするため）。画面に戻ってきたとき・表示を切り替えたときに、折りたたみの中へ移る。
- サマリー（「今日まで」「今週」「担当未定」）は、いまのまま（未完了だけを数えている）。
- 一覧が「未完了 0 件・完了だけ」のときは、0 件のときの説明（何をする画面か、「やることを追加」）を出し、その下に折りたたみを出す。
- 並びの計算は `src/shared/domain/taskPresentation.ts` に置き、ユニットテストを付ける（画面に残す「この画面で完了にしたもの」の扱いは、ID の集合を引数で受け取る形にする）。

## 変えないもの

- やることの API（完了から 14 日で返らなくなる決まりも、そのまま）。週ビューの締切のチップと残りの数（もともと未完了だけ）。
- 行の見た目と操作（チェック、担当、編集）、フォーム、サマリーの数え方。
- 取り直しの間は、前の一覧を表示したままにする扱い。

## テスト

- ユニット：完了したものが各表示から外れること、未完了のない予定のカードが出ないこと、進捗の数、折りたたみの中身と並び（完了の新しい順）、「自分の担当」での数え方、「この画面で完了にしたもの」がその場に残ること。
- Playwright（API をモック、合成データ）：
  - 開いたとき、完了したやることと、すべて完了した予定のカードが見えないこと。折りたたみ「完了したやること（N件）」が閉じていること。
  - 完了にした行が、その場に残ること（ほかの行が動かないこと）。表示を切り替えると、折りたたみに移ること。
  - 折りたたみを開いてチェックを外すと、未完了に戻り、元の場所に出ること。
  - 完了だけのときの表示。
  - 390px と 445px で横にはみ出さないこと。
- 既存のテストがすべて通ること（完了したものが一覧に出ることを前提にしたテストは、新しい決まりに直す）。

## 受け入れ基準

- 「やること」を開くと、未完了のやることだけが見える。すべて完了した予定のカードは出ない。
- 完了したやることは、折りたたみを開けば見られ、未完了に戻せる。
- 完了にした直後に、行が消えて一覧が動かない。
- `src/worker` と `migrations` に変更がない。
- `pnpm typecheck` / `lint` / `test` / `e2e` が通る。`pnpm db:generate` で差分が出ない。
