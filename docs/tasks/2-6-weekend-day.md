# タスク 2-6：S2「週末の1日」

- ブランチ名: `phase2/2-6-weekend-day`（最新の main から分岐）
- 作業前に読むもの: [AGENTS.md](../../AGENTS.md)（特に「絶対に守ること」1・2・5、UI の規約）、[docs/02-screens.md](../02-screens.md)（予定の見え方、S2、モック `docs/mocks/02-weekend-day.png`）、[docs/03-architecture.md](../03-architecture.md)（「freeWindows：共通の空き」）、[docs/19-busy-sharing.md](../19-busy-sharing.md)、`src/shared/domain/freeWindows.ts`、`src/shared/domain/weekendTimeline.ts`、`src/client/features/week/WeekPage.tsx`、`src/client/features/week/EventDialog.tsx`
- **人間の確認が必要**（ほかのメンバーの空き状況を画面に出す）

## 目的

1日を縦のタイムラインで見て、家族それぞれの予定と、全員が空いている時間帯を確かめ、その空き時間から家族の予定を作れるようにする。週末の計画を立てるための画面。

## プライバシー（最優先）

- ほかのメンバーの個人の予定について画面に出すのは、**埋まっている時間帯（斜線の「予定あり」）だけ**。`/week/busy` が返す以上の情報を作らない。
- 自分の個人予定（タイトル付き）は、本人の画面にだけ出す（`/week/personal` の結果だけを使う）。
- 空き状況と個人予定は、ブラウザの永続ストレージに保存しない。週ビューと同じ query cache を使い、ログアウト・アカウント切替・家族の切替で消える状態を保つ。
- サーバー側は変更しない（下の「変えないもの」）。

## 対象範囲

### 入口と URL

- URL は `/day/YYYY-MM-DD`。ログインしていて、家族の準備ができている利用者だけが見られる（週ビューと同じ条件。満たさないときの行き先も週ビューと同じ）。
- 不正な日付、対応年の範囲外（1970〜2050 の外）のときは、週ビューへ戻す。
- 週ビューの週末・祝日カードに、「この日を詳しく見る」のリンクを1つ足す（カード全体をタップ可能にはしない。カードの中に既存のボタンがあるため）。平日の行には足さない。
- 画面の「戻る」は、その日を含む週の週ビューへ戻る。ブラウザの戻るでも同じ週に戻れること。
- 下のタブバーは週ビューと同じものを出し、「週」を選択中にする。

### データ

- その日を含む週について、既存の `/week`、`/week/personal`、`/week/busy` を使う。新しい API は作らない。3つは独立に取得し、どれかが失敗・遅延しても、ほかは表示する。
- 計算は `getFreeWindows` と、2-5 で作った整形の関数を使う。1日用に足りない整形（縦方向の位置と高さ、列の割り当てなど）は `src/shared/domain` の純粋関数にして、ユニットテストを付ける。
- 共通の空きの対象時間帯は、週ビューと同じ 8〜20 時にする（2つの画面で「みんな空き」の時間が食い違わないようにするため）。

### 画面

- **ヘッダー**：戻る、日付（例「10月10日」）、曜日、補足（連休なら「3連休の1日目」、祝日名・休園があればそれも）、凡例の説明文（「斜線はほかの家族の『予定あり』、点線枠は自分だけに見える予定」）。
- **メンバー列のタイムライン**：縦軸は 7〜21 時（1時間 48px）、横にメンバーの列（順番は週ビューの凡例と同じ）。列の上にメンバー色の点と名前。メンバーが多くて 390px に収まらないときは、タイムラインの中だけを横スクロールにする（ページ全体は横スクロールさせない）。
  - **家族予定**：対象メンバーの列に、メンバー色の薄い背景とタイトルで出す。対象メンバーが空の予定は、全員の列にまたがる1つのブロックにする。繰り返しの予定には繰り返しのアイコンを付ける。
  - **担当つきの予定**：担当者の列にも、「担当」のラベル付きで出す（前後の余裕は 0 分。余裕を付けるかは送迎の機能を作るときに決める）。担当者が対象メンバーでもある場合は、1つのブロックに「担当」を添える。
  - **ほかの家族の個人の予定**：その人の列に、斜線のグレーと「予定あり」。色だけに頼らず、文字も出す。
  - **自分の列**：ほかの人と同じ斜線の「予定あり」（家族に見えている内容）に加えて、自分の個人予定（`/week/personal`）を点線枠・鍵アイコン・「自分だけ」で重ねて出す。
  - **状態の出し分け**：`not_shared` の大人の列には、列の上に「個人の予定は未共有」。`unavailable` の大人の列には「取得できませんでした」と出し、斜線のブロックは出さない。
  - 重なる予定は、同じ列の中で横に分けて並べる。短い予定でも、タイトルが読める最小の高さを確保する。
- **終日の予定**：タイムラインの上に、終日の家族予定と、自分の終日の個人予定を並べる。
- **時間帯の外の予定**：7 時より前・21 時より後だけにある家族予定と自分の個人予定は、タイムラインの下に一覧で出す。時間帯をまたぐ予定は、タイムラインの端で切って出す。
- **共通の空き**：全列にまたがる点線枠と薄いアクセント色の帯、ラベル「みんな空き 12:00–19:00」。`unavailable` の人がいるときは帯を出さず、「空き状況を取得できない人がいるため、共通の空きは表示していません」と出す（週ビューと同じ決まり）。`not_shared` の人がいるときは、家族予定の分だけで計算し、「個人の予定を共有していない人がいます」と添える。
- **候補の家族予定**：タイムラインの該当する時間に、白いカードで重ねる。タイトル、「候補」バッジ、時間、対象メンバー（空なら「家族全員」）、持ち物チップ。
- **予定を作る**
  - 共通の空きの帯は、本物の `<button>` にする（`aria-label` は「12:00 から 19:00 の空き時間に予定を追加」のように時刻入り）。押すと、既存の予定の作成ダイアログを、その日・**帯の開始時刻から1時間**（帯が1時間より短ければ帯の終わりまで）を初期値にして開く。
  - 下部のボタン：「家族の予定を追加」（主）は、その日を初期値にして作成ダイアログを開く（時刻の初期値は既存の決まりのまま）。「空き時間から探す」（副）は、最初の共通の空きの帯までスクロールしてフォーカスを移す。共通の空きがないとき・出せないときは、押せない状態にして理由を添える。
  - 家族予定のブロックと候補のカードを選ぶと、既存の編集ダイアログを開く。繰り返し予定は、週ビューと同じ「繰り返し予定の変更は準備中」の案内にする。
  - 作成・編集・削除のあとは、この画面と週ビューの両方に反映される。
- **読み込みと失敗**：家族予定の取得に失敗したときは、週ビューと同じ形の案内と再試行。空き状況・個人予定だけの失敗は、タイムラインの上に控えめな案内を出し、家族予定は表示する。
- **読み上げ**：タイムラインとは別に、メンバーごとの予定と共通の空きを文で並べた一覧を用意する（視覚的には隠してよい）。

## 対象範囲の外

- 候補への返事の状況（「ママ OK · パパ 返事待ち」）。データがまだないので出さない。
- 添付、締切、ドラッグでの時間変更、空き帯の中の任意の位置をタップして時刻を決めること。
- 平日の行から、この画面へ入るリンク（URL を直接開けば、平日でも表示できる）。

## 変えないもの

- サーバー側の API、D1 のスキーマ、認可。`src/worker` と `migrations` に変更を入れない。
- 週ビューの既存の表示と挙動（足すのは、週末・祝日カードのリンク1つだけ）。週末カードの空きタイムラインと「みんな空き N時間」。
- 予定の作成・編集ダイアログの項目、検証、保存の挙動（足すのは、開くときの初期値の受け渡しだけ）。
- 「家族」タブ。

## テスト

- ユニット（表示用の純粋関数）：縦の位置と高さ、7 時・21 時をまたぐ予定の切り取り、時間帯の外の予定の振り分け、列の割り当て（対象メンバーが空・担当・担当かつ対象）、重なる予定の横並び、空き帯から作る予定の初期値（1時間・1時間未満の帯）、「3連休の N 日目」の文。
- Playwright（API をモック、合成データ）
  - 週末カードのリンクから開けること、戻ると同じ週に戻ること、URL を直接開けること、不正な日付で週ビューに戻ること。
  - 家族予定・担当・候補・斜線の「予定あり」・「自分だけ」・終日・時間帯の外の予定が、与えたデータどおりの列と時間に出ること。
  - ほかのメンバーの「予定あり」に、予定の名前などが一切出ないこと。別のアカウントで開いたとき、前のアカウントの「自分だけ」の予定が出ないこと。
  - `not_shared` と `unavailable` の出し分け（`unavailable` のとき、共通の空きの帯が出ないこと、「空き時間から探す」が押せないこと）。
  - 空き帯を押すと、作成ダイアログがその日・帯の開始時刻から1時間で開くこと。保存すると、この画面と週ビューに出ること。
  - 家族予定の編集・削除、繰り返し予定の案内。
  - `/week/busy` や `/week/personal` が失敗・遅延しても、家族予定が表示され、予定を追加できること。
  - 390px と 445px で、ページ全体が横にはみ出さないこと。メンバーが多いときに、タイムラインの中だけが横スクロールになること。
- 既存のテストがすべて通ること。
