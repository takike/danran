# タスク 3-2 フォローアップ：振替の「保存」ボタンが空白に見える

- ブランチ名: `phase3/3-2-followup-move-save-button`（最新の main から分岐）
- 作業前に読むもの: [AGENTS.md](../../AGENTS.md)、`src/client/features/routines/RoutineInstances.tsx`、`src/client/features/routines/RoutinesPage.tsx`

## 背景

実機確認で、「繰り返し」の画面の「振替を設定」のフォームにある決定ボタンが、文字のない白いボタンに見えるという指摘があった（「やめる」の左のボタン）。機能は動いているが、何のボタンか分からない。

原因：`RoutineInstances.tsx` の `buttonClass` が `bg-surface` と `text-ink` を含んでいて、「保存」ボタンはそこに `bg-accent text-surface` を足している。背景は `bg-surface`（白）が、文字は `text-surface`（白）が効き、白地に白い文字になっている。

## 目的

振替の「保存」ボタンを、ほかの主ボタン（繰り返し予定の作成フォームの「保存する」など）と同じ見た目（アクセント色の背景に白い文字）で表示する。

## 対象範囲

- `RoutineInstances.tsx` のボタンのクラスを、**同じ種類のユーティリティ（背景色・文字色・枠線）が1つの要素に2つ重ならない**形に直す。副ボタン用と主ボタン用を分けるなど、やり方は任せる。
- 同じ重なり方をしている箇所が、`src/client/features/routines/` のほかのボタンにないかを確かめ、あれば同じように直す。見つけた箇所は PR の説明に書く。
- 保存中（「保存中...」）と無効のときも、文字が読めること。

## 変えないもの

- 振替・休みの挙動、API、文言、ボタンの並びと大きさ。
- 「繰り返し」の画面のほかの部分の見た目。
- `src/worker`、`migrations`。

## テスト

- Playwright：振替のフォームを開いた状態で、「保存」ボタンの文字が見えていること。**ボタンの背景色と文字色が異なる**ことを、計算後のスタイルで確かめる（白地に白のような状態を検出できるテストにする）。「やめる」ボタンも同じ確認をする。
- 既存のテストがすべて通ること。

## スクリーンショットと docs

- `docs/screenshots/s4-routines.png` を、**振替のフォームを開いた状態**で撮り直す（390px 幅、合成データ）。今回の問題は、スクリーンショットにフォームが写っていなかったために、レビューで見つけられなかった。
- docs の更新は不要。

## 受け入れ基準

- 振替の「保存」ボタンが、アクセント色の背景に白い文字で表示される。
- 背景色と文字色が同じになる状態を、テストが検出できる。
- `pnpm typecheck` / `lint` / `test` / `e2e` が通る。

PR を作成したらマージせずに止まること。
