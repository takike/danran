# 01. コンセプト

## 一言で

**「ルーティンは背景に、週末は前景に」**。家族の予定を、重要度（非ルーティン度）に応じて大きさを変えて見せるカレンダー。

## 解きたい課題

小さな子どもがいる共働き家庭では、次のことが起きがち。

1. **平日はほぼルーティン**（仕事・保育園・習い事）。等幅のカレンダーだと、平日が画面の大半を占めるのに情報量は少ない。
2. **週末の計画が一番大事なのに、一番雑に扱われる**。家族全員の空きを見て予定を立てたいが、各自の予定は別々のカレンダーにある。
3. **保育園のプリントが紙で来る**。行事・締切・持ち物が1枚に混在し、冷蔵庫に貼られたまま見落とされる。
4. **繰り返し予定の例外処理が面倒**。祝日休み、振替、行事との重複などを毎回手で直している。
5. **個人カレンダーを丸ごと共有したくない**。仕事の予定の中身まで家族に見せる必要はないが、「いない」ことは伝えたい。

## プロダクト原則

1. **サイズは非ルーティン度で決める**。曜日で決め打ちしない。平日でも行事があれば大きく、予定のない祝日は小さくてよい。「平日＝小、土日祝＝大」はあくまでデフォルト値。
2. **既定はプライベート、共有は明示的に**。個人カレンダーの予定は、既定では「予定あり（free/busy）」としてだけ家族に見える。中身を見せるのはルールか本人の選択による。
3. **自分の予定は自分には全部見える**。プライバシーは他の家族からの見え方の話で、本人の画面では中身まで表示する（「自分だけ」マーク付き）。
4. **入力は極力しない**。プリントは撮るだけ、公開はルールで自動、迷うものだけ週1でまとめて聞く。1件ずつのチェック作業は作らない。
5. **やることは予定から芋づる式に出てくる**。予定を入れたら、締切・準備・持ち物・連絡事項が自動で TODO になる。
6. **Google Calendar を正本にする**。アプリを開かない家族にも、普段の Google Calendar で家族予定が見えるようにする。アプリ固有の付加情報だけをアプリ側に持つ。

## 対象ユーザー（初期）

- 開発者本人の家族：大人2人（それぞれ Google アカウントあり）、未就学児2人（アカウントなし）
- 東京在住、日本の祝日・保育園の年間行事に沿って生活
- 大人の一方または両方が、会社の Google Workspace で仕事の予定を管理している可能性がある

将来の一般公開では「未就学〜小学生の子どもがいる共働き世帯」を想定する。

## 差別化（TimeTree 等との違い）

| 観点 | 一般的な共有カレンダー | Danran |
|---|---|---|
| レイアウト | 全日等幅 | 非ルーティン度で伸縮（週末が主役） |
| 個人予定 | 共有カレンダーに手で入れ直す | Google Calendar の free/busy を自動で重ねる |
| プリント | 手入力 | 撮影 → 抽出 → 確認 → 一括登録（写真を添付） |
| 繰り返し | 単純な繰り返し | 祝日スキップ・振替・行事との重複検出 |
| TODO | 別アプリ | 予定に紐づく「やること」を自動生成 |

## 用語集

| 用語 | 意味 | コード上の名前（目安） |
|---|---|---|
| 家族 | アプリの利用単位 | `family` |
| メンバー | 家族の構成員。Google アカウントを持つ大人と、持たない子どもがいる | `member`（`kind: adult \| child`） |
| 家族カレンダー | Danran が作る、家族共有の Google カレンダー | `familyCalendarId` |
| 個人カレンダー | 各大人の Google カレンダー（仕事用を含む） | `personal calendar` |
| 予定あり | 個人カレンダーの予定を中身なしで表示したもの | `busy block` |
| 家族予定 | 家族カレンダー上の予定 | `family event` |
| ルーティン | 繰り返し予定のうち、いつもどおりのもの | `routine` |
| いつもと違う日 | 平日のうち、非ルーティンの予定がある日 | `exceptional day` |
| 共通の空き | 家族全員（対象メンバー）が空いている時間帯 | `common free window` |
| 送迎・担当 | 予定や TODO に紐づく担当者 | `assignee` |
| 候補 | まだ確定していない家族予定 | `status: tentative` |
| プリント取り込み | 撮影画像から予定等を抽出する処理 | `import job` |
| やること | 予定に紐づく TODO | `task` |
| 公開 | 個人予定を家族に見せること。粒度は3段階 | `visibility: busy \| title \| details` |
| 公開ルール | 公開を自動で決める条件 | `publish rule` |
| 週1まとめ | 公開判断を週に1回まとめて聞く通知と画面 | `weekly digest` |
